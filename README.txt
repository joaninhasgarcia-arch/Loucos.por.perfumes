README — PÁGINA DO GRUPO DE PERFUMES

CONTEÚDO DO PACOTE
- index.html: página de entrada do grupo.
- README.txt: instruções de publicação.

O QUE JÁ ESTÁ CONFIGURADO
- Imagem dos perfumes embutida no próprio index.html.
- Botão verde para entrar no grupo.
- Link do WhatsApp configurado.
- Layout responsivo para celular e computador.
- Nenhuma imagem, biblioteca ou pasta adicional é necessária.

PUBLICAÇÃO NO NETLIFY
1. Baixe e extraia o arquivo pagina-grupo-perfumes.zip.
2. Entre no painel do Netlify e abra o site desejado.
3. Vá até a área de Deploys e use a opção de publicação manual.
4. Envie os arquivos extraídos, garantindo que index.html fique diretamente na raiz
   da pasta publicada.
5. Aguarde o deploy terminar e abra novamente o endereço do site.

ATENÇÃO AO ERRO "PAGE NOT FOUND"
Esse erro costuma ocorrer quando o Netlify publica uma pasta diferente daquela onde
está o index.html. Dentro deste ZIP, os arquivos estão diretamente na raiz:
index.html
README.txt

Não coloque o index.html dentro de uma subpasta antes de publicar. Se estiver usando
um repositório Git, confira também se o diretório de publicação (Publish directory)
aponta para a pasta que contém o index.html.

TESTE
Abra o index.html no navegador para conferir a página. Clique no botão para testar
o redirecionamento ao WhatsApp. O acesso ao grupo depende de o convite continuar ativo.
